# GPS Tracker（Windows PC 版）

把 GPS Tracker 的紀錄儀表板與 GPS 定位器的路線模擬合併成一個 Windows 桌面程式。

- 紀錄端直接使用現有的 `gpstracker-web` 儀表板。
- PC 端沒有 GPS，路線由模擬引擎產生；模擬紀錄會以設定的裝置名稱（預設 `PC`）、`source: "simulated"` 上傳。
- 桌面版隱藏拍照、步數與圖片分享功能；好友之間的位置分享是另外提供的新功能。
- 每台電腦都是獨立裝置（例如桌機 `PC`、筆電 `NB`）；模擬紀錄不與手機紀錄合併。多台電腦可以使用不同裝置名稱。

## 系統需求

- Windows 10／11 x64
- Microsoft Edge WebView2 Runtime（Evergreen）
  - Windows 11 通常已內建；如果沒有，啟動程式時會顯示下載頁面，不會直接結束。
- 看地圖、同步資料與檢查更新需要網路；已經同步過的紀錄可以離線瀏覽。

本發佈版是 **self-contained、win-x64**，其他電腦不需要另外安裝 .NET Runtime。

## 安裝與啟動

1. 解壓縮 `GpsTrackerPc-win-x64.zip`。
2. 保持 `GpsTrackerPc.exe`、`web\`、`Simulator\` 在同一個資料夾。
3. 執行 `GpsTrackerPc.exe`。

程式第一次啟動會建立本機資料夾：

```
%LOCALAPPDATA%\GpsTrackerPc\
  data\              同步下來的網站資料
  routes\            儲存的路線
  favorites.json     收藏地點
  settings.json      裝置名稱等本機設定
  github-token.bin   DPAPI 加密後的 GitHub Token
  sync-cache.json    同步用的 ETag 快取
  map-settings.json  底圖與跟隨模式設定
  theme.json         淺色／深色／系統主題設定
  tray.json          縮小到系統匣的設定
  storage.json       自訂本機資料夾路徑
  social.json        好友／群組清單、分享開關與分享裝置識別碼
```

本機資料夾可在「設定 → 本機資料夾」按「選擇資料夾…」指定其他磁碟或資料夾；設定後需重新啟動程式，原本的資料不會自動搬移。未指定時使用上面的 `data\`。

## 第一次設定 GitHub Token

Token 只用來「寫入」紀錄（GPX 匯入、模擬紀錄上傳）；閱讀公開資料不需要 Token。

1. 在主畫面按「設定」。
2. 在「GitHub Token」輸入具有該公開倉庫寫入權限的 Token。
3. 按「儲存 Token」。

Token 會用 Windows DPAPI（CurrentUser）加密後存在本機，畫面只顯示「已設定／未設定」，不會顯示內容，也不會寫進程式碼或記錄檔。要更換或刪除 Token，回到同一個設定畫面操作。

## 設定裝置名稱

裝置名稱會用在上傳紀錄（GPX 匯入與模擬紀錄），預設是 `PC`。

1. 按「設定」。
2. 在「裝置名稱」輸入名稱，例如 `PC` 或 `NB`。
3. 按「儲存裝置名稱」。

名稱不能空白。若和網站上手機（非模擬）的裝置同名會拒絕儲存；若和另一台模擬裝置同名會先警告，因為上傳後會合併成同一台裝置。多台電腦請使用不同名稱。

## 設定主題

設定畫面可選「淺色」、「深色」或「系統預設」。選擇會存在本機，下次開啟沿用；系統預設會跟著 Windows 的應用程式主題。修改裝置名稱、主題或自動檢查設定後，可按畫面下方「套用」一次儲存。

## 縮小到系統匣

「設定 → 視窗行為」可開啟「縮小視窗時收到工具列圖示區（系統匣）」。開啟後，主視窗縮小會隱藏到系統匣，模擬播放會在背景繼續；系統匣圖示按兩下可回到主視窗，右鍵選單可顯示主視窗、顯示模擬路線或結束程式。按關閉（X）仍會結束程式。

## 資料同步

- App 啟動時會自動同步一次。
- 主畫面可按「立即同步」。
- 同步來源是公開的 `gpstracker-web/data/`，會先下載 `manifest.json`，再下載缺少或變更的紀錄檔與 `meta.json`、`metro.json`、`steps.json`、`voyager.json`。
- 下載失敗會保留本機舊檔，不會清空資料。
- 主畫面會顯示上次同步時間與結果。

## GPX 匯出

1. 按「匯出 GPX」。
2. 勾選一筆或多筆紀錄。
3. 按「選擇資料夾並匯出」，選一個資料夾。
4. 每筆會存成 `<trackId>.gpx`，畫面會顯示成功與失敗筆數。

## GPX 匯入

1. 按「匯入 GPX」，可以多選檔案，也可以把 `.gpx` 拖進視窗。
2. 視窗會先顯示每個檔案的日期、距離、時間、點數與無時間點數量。
3. 選擇移動方式（預設「未知」）。
4. 按「開始匯入」並確認公開警告。

匯入會依序一筆一筆上傳；重複、解析失敗或上傳失敗的檔案會標示原因並跳過，不會中斷整批。上傳時會使用「設定」裡的裝置名稱。紀錄會寫入公開的 GitHub 倉庫，任何人都看得到路線與時間。

## 模擬路線

1. 主畫面按「模擬」。
2. 地圖上點擊新增路線點；拖曳圓點可移動；右側清單可調整順序、刪除與設定停留秒數。
3. 可設定速度（走路 5／跑步 10／騎車 18／開車 40 km/h，或自訂 0.5–500）、循環路線、速度自然起伏與依 GPX 時間播放。
4. 可新增 GPS 中斷時段（開始秒數、持續秒數）。
5. 可搜尋地點（Nominatim，每秒最多一次）、收藏地點、用隨機漫步／環狀產生路線。
6. 可匯入 GPX／KML、匯出 GPX／KML，或把路線存在 `%LOCALAPPDATA%\GpsTrackerPc\routes\`。
7. 修改名稱、速度或播放選項後，可按「套用」一次套用到目前路線。

### 底圖與跟隨

- 底圖可選：簡易地圖（OpenFreeMap，預設）、衛星（Esri）、台灣電子地圖（內政部國土測繪中心 NLSC）、無底圖。
- 底圖選擇會存在本機，下次開啟沿用；右下角會顯示目前底圖的圖資來源。
- 切換底圖不會清掉路線、路線點、播放軌跡或目前位置。
- 「跟隨目前位置」預設開啟：只有目前位置進入畫面外圍 15% 時才平移一次，不會每次更新都移動鏡頭，也不會自動改變縮放層級。可以關閉。
- 「定位」按鈕會直接平移到大頭針目前位置，不會改變縮放。
- 「📍 目前位置」會使用 Windows 定位服務（桌機會使用 Wi-Fi／基地台定位）取得本機位置，並用藍色大頭針標在地圖上；如果 Windows 未允許定位，會顯示原因。
- 「回首頁」只會切回紀錄網站首頁，不會關閉程式；模擬路線編輯保留在背景，再次按「模擬」會回到同一個編輯狀態。

### 播放

- 「開始」後以每秒取樣推進；可「暫停」「繼續」「停止」。
- 倍速支援 1／2／4／8。
- 會顯示進度、已過時間、目前速度與已走距離。
- GPS 中斷期間不記錄位置，地圖上的播放標記會變紅並顯示中斷提示。
- 「直接產生」會直接算完整條路線；循環路線可指定圈數。

### 上傳模擬紀錄

1. 先即時播放完成，或按「直接產生」。
2. 按「上傳成紀錄」。
3. 確認摘要（日期、距離、時間、點數、設定的裝置名稱、來源 `simulated`），必要時修改開始時間（預設現在）。
4. 按「確認上傳」並確認公開警告。

模擬紀錄會轉成與網站匯入相同的格式；GPS 中斷期間的點不會寫入。上傳沿用 GitHub Contents API，遇到 409／422 會重讀 manifest 合併後重試。

## 好友 & 群組

主畫面按「好友」會開啟獨立分頁；清單在左側，目前位置地圖在右側。

### 互相分享目前位置

1. 按右上角「分享我的位置」，程式會用 Windows 定位服務取得位置（桌機會用 Wi-Fi／基地台輔助）。
2. 開啟後每 30 秒更新一次位置；關閉時會通知還在線上的好友「已停止分享」。
3. 好友必須也在同一個好友連線或群組裡開啟分享，雙方才看得到彼此位置。
4. 位置地圖會顯示線上、離線與停止分享的狀態，以及與自己的距離。

如果 Windows 沒有允許定位，畫面會顯示原因；請到「Windows 設定 → 隱私權 → 位置」允許桌面程式使用位置。

### 新增好友

1. 其中一方按「邀請好友」，建立一個好友連線，並把產生的 `GTF1-...` 邀請碼傳給對方（訊息、電子郵件等）。
2. 對方在「好友」分頁按「新增好友」，貼上邀請碼。
3. 雙方都開啟分享後，就會出現在彼此的清單與地圖上。

### 建立與加入群組

1. 按「建立群組」，輸入名稱，把產生的邀請碼傳給朋友。
2. 朋友切到「群組」分頁按「加入群組」貼上邀請碼。
3. 群組清單會顯示線上／成員人數；點選群組後，下方會列出成員，地圖只顯示這個群組的位置。

### 隱私

- 位置會先用 AES-256-GCM 加密，再經由 `ntfy.sh` 中繼傳送；中繼服務只看得到密文與隨機主題。
- 邀請碼包含分享金鑰，等於分享權杖；只傳給信任的人，不要公開張貼。
- 好友與群組清單只存在本機 `social.json`，不會上傳到 GitHub。
- 這個功能需要網路；ntfy.sh 無法連線時，清單仍可編輯，但不會更新位置。

## 版本與自動更新

目前版本會顯示在主視窗標題列與設定畫面；版本號以 `GpsTrackerPc.App.csproj` 的 `<Version>` 為唯一來源。

- 主視窗按「檢查雲端更新」會開啟更新畫面，顯示「目前版本 → 新版本」與 Release 更新說明。
- 啟動時一天最多自動檢查一次；設定可選穩定版或測試版（`gpstracker-desktop-beta`）通道，並可關閉自動檢查。
- 可開啟「背景下載」：下載時顯示進度與速度，可暫停／繼續（HTTP Range 續傳），預設避開行動寬頻等可能計量的網路。
- 下載完成可設定「自動安裝」或由工具列「安裝更新」手動確認；安裝後工具列顯示「請重啟程式」與「重啟程式」按鈕。
- 下載失敗會依 30 秒／2 分鐘／10 分鐘退避重試最多 3 次；有系統匣圖示時會顯示通知。
- 下載與安裝前會檢查磁碟空間；EXE 有簽章時驗證鏈結，未簽章會明確提示（目前以 SHA-256 為主要驗證）。
- 只接受比目前版本新的版本；同版或舊版不會安裝（降版保護）。
- 下載後會用 Release 附的 SHA-256 檢查；不符合會刪除下載檔。EXE 與 ZIP 並存時只使用同檔名的檢查碼。
- 安裝只替換 EXE，`.old` 會保留 7 天，可在設定畫面「回復上一個版本」。
- 重啟前會暫停模擬並暫存；重啟後詢問「從暫停點繼續／直接存檔並結束／不存檔放棄」，可記住選擇並在設定重設。
- 已安裝或更舊的背景下載資料夾會在啟動成功後清理；放了 7 天以上的 `.part` 也會刪除。
- 程式只允許一個實例；更新重啟時新行程會等舊行程結束再接手。

## 待上傳紀錄與網路

- 模擬紀錄上傳失敗，或重啟時選擇存檔，會先放進本機待上傳清單（最多 200 筆）。
- 每 5 分鐘比對網站 manifest 並自動補傳；預設每日上限 20 筆，可在設定調整。開啟自動補傳前會提示紀錄會公開上傳。
- 工具列的「待上傳」可查看失敗次數與原因、立即補傳（跳過每日上限）或刪除。
- 網路中斷時會暫停模擬播放、背景補傳與同步，主視窗顯示離線橫幅；恢復連線後自動繼續。
- 播放面板會標記網路中斷的模擬時間區段。

更新來源：`https://github.com/wahaha232/GPS-TRACKER-PC/releases/tag/gpstracker-desktop-latest`（測試版：`gpstracker-desktop-beta`）

版本變更記錄請看 `CHANGELOG.md`。

## 隱私與注意事項

- GPX 匯入與模擬上傳會寫入**公開**的 GitHub 倉庫，路線、時間與裝置名稱任何人都看得到。
- Token 只存在本機並以 DPAPI 加密；不要把 `github-token.bin` 或 Token 分享給別人。
- 桌面版沒有拍照、步數與圖片分享功能；好友／群組的位置分享是可另外開啟的功能。
- 好友位置以端對端加密經 ntfy.sh 中繼；邀請碼就是分享權杖，請只傳給信任的人。
- 地圖底圖可使用 OpenFreeMap、Esri World Imagery、NLSC 或無底圖；前三種需要網路。

## 疑難排解

- **出現「找不到 WebView2 Runtime」**：依畫面按鈕開啟官方下載頁，安裝 Evergreen Runtime 後重新啟動。
- **同步失敗**：確認網路；失敗不會刪除既有資料，可稍後再按「立即同步」。
- **上傳失敗**：確認 Token 有寫入權限，且尚未過期；出現「Bad credentials」代表 Token 無效或已過期，請重新產生並儲存；重複紀錄會被跳過。
- **更新失敗**：程式會保留舊版；可稍後再從設定畫面檢查更新。
